# Air Quality Prediction — ML Pipeline with L1 & L2 Regularization

A machine learning pipeline built to predict **Air Quality Index (AQI)** 
using an Air Quality dataset sourced from Kaggle. The project benchmarks 
multiple regression and classification models with L1 (Lasso) and L2 (Ridge) 
regularization to analyze their performance impact.

## 🔍 Overview
- **Regression Task:** Predict the continuous AQI value
- **Classification Task:** Predict the AQI Bucket (Good, Moderate, Satisfactory, etc.)

## 📊 Dataset Features
Pollution-related attributes including PM2.5, PM10, NO, NO2, NOx, NH3, 
CO, SO2, O3, Benzene, Toluene, and Xylene — along with City and Date metadata.

## 🤖 Models Used
**Regression:** Linear Regression, Lasso, Ridge, Decision Tree, Random Forest  
**Classification:** Logistic Regression (L1 & L2), SVM, Random Forest

## 📈 Evaluation Metrics
- **Regression:** MSE, RMSE, R² Score  
- **Classification:** Precision, Recall, F1-Score (Macro/Micro/Weighted), 
  Confusion Matrix, ROC-AUC Curves

## 🛠️ Tech Stack
Python · scikit-learn · pandas · NumPy · Matplotlib · Seaborn · Google Colab
